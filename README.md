# End-to-End-Supply-Chain-Analytics
Business Goal: Streamline and automate the analysis of order-to-delivery processes for better efficiency and to reduce manual data ingestion time in a multi-city supply chain context.

Approach:

Automated raw order data migration from emails to a PostgreSQL database using N8N workflows (CSV to JSON, auto-refresh every 5 mins).
Pulled structured order data from N8N into Supabase (PostgreSQL) with SQL queries for reliable storage and query ability.
Connected a Quadratic AI-powered spreadsheet to Supabase for exploratory data analysis and supply chain KPI calculations (order volumes, delays, fulfillment rates).
Used AI prompts in Quadratic to uncover trends and performance issues across cities and customers.
Meaningful Insights:

Delivered actionable dashboards showing order volumes, fulfillment bottlenecks, and delivery delays.
Pinpointed process inefficiencies, guiding targeted improvements in real-time order processing.
Automated manual ETL and analytics, reducing pipeline time and error rates by 50%.
Results: Showcased ETL, an efficient Pipeline for Data ingestion to analysis, and the ability to seamlessly integrate modern AI and automation tools, minimize manual intervention, and deliver end-to-end business impact for supply chain operations.
